\# Camera AI Security System



Hệ thống giám sát an ninh thông minh sử dụng ESP32-CAM, AI biên, Spring Boot Backend, MySQL, MinIO và Mobile App.



\## Modules



\- `backend/`: Java Spring Boot backend

\- `mobile/`: Mobile application

\- `firmware/`: ESP32-CAM firmware

\- `docs/`: Requirements, diagrams, API specs, database design

\- `deployment/`: Docker compose, MySQL, MinIO configuration



\## Tech Stack



\- Backend: Java Spring Boot

\- Database: MySQL

\- Object Storage: MinIO

\- Notification: Firebase Cloud Messaging

\- Realtime: WebSocket

\- Firmware: ESP32-CAM

\- AI Edge: TFLite Micro
